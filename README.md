# Programación orientada a objetos con Python

Material oficial de la serie **«Programación orientada a objetos con Python»** del canal **NonLinear Academy**.

## Hilo conductor
A lo largo de ocho episodios construimos y ampliamos objetos matemáticos reales (`Fraccion`, `Vector` y `Polinomio`) con definiciones formales, invariantes explícitos y ejercicios resueltos hasta culminar en un proyecto integrador de aritmética racional exacta sobre $\mathbb{Q}[x]$ y $\mathbb{Q}(x)$.
